# assets

This directory holds the small test/fixture clips needed to reproduce
the paper's tables and figures. Larger source datasets are *not*
committed; they must be obtained from their upstream maintainers.

## What is tracked here

- `davis_mp4/` — 10 DAVIS-2017 sequences used by the champion eval
  (blackswan, libby, swing, camel, dance-twirl, goat, scooter-black,
  bmx-trees, parkour, kite-surf), re-encoded as mp4 at 24 fps from
  the official DAVIS-2017 480p frames.
- `scene_cut/` — three synthetic hard-cut clips used in Appendix B
  (blackswan→goat, kite-surf→dance-twirl, libby→camel; cut at frame 32).
  Built by `scripts/scene_cut_eval.py:build_cut_clip` from
  DAVIS-2017 source frames.
- The smoke-test example in the top-level README uses
  `assets/davis_mp4/blackswan.mp4` directly; no separate test
  fixture is needed.

## What is **not** tracked (download separately)

- `davis/` — full DAVIS-2017 raw frames (1.6 GB).
  Download from the [DAVIS-2017 official page](https://davischallenge.org/davis2017/code.html)
  and place the per-sequence frame directories under
  `assets/davis/<seq>/00000.jpg ...`. Then run
  `python scripts/davis_to_mp4.py` to (re)generate `assets/davis_mp4/`.
- `davis_heldout20_mp4/` — the 25 additional DAVIS-2017 sequences
  used for the unused-DAVIS-19 held-out evaluation (Table 14).
  Regenerated by `scripts/davis_to_mp4.py` once you have the raw
  DAVIS-2017 frames.
- `crossds_raw/`, `crossds_512/` — cross-dataset eval sources
  (Table 13). The 15 clips come from 7 public sources:
  Big Buck Bunny (Blender, CC-BY), Sintel (Blender, CC-BY),
  Jellyfish (test-videos.co.uk), MDN CC0 samples,
  the learning-container sample, and Intel IoT public sample
  videos. See `scripts/phase3_crossds_local.py` for the canonical
  source URLs and the trim windows we use.

If you only want to reproduce the headline numbers on the 10
in-domain DAVIS sequences, the tracked `davis_mp4/` directory is
sufficient.
